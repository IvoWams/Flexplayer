# Flexplayer NodeJS client

This repository contains everything to set up on a Raspberry PI with a Debian (Raspbian) setup. It consists of the following folders:

- src/
The typescript source code

- doc/
Output of different linux commands for testing purposes

- interface/
Config for the OSD when the setup button is pressed during operation.

- raspberry_pi
Files needed to run the app on the PI.

- webapp/
Files for the webserver to host.

## Webserver

The webapp/ folder will be hosted by a Webserver on the PI (not using Express, but a simple socket setup, as simple and lightweight as possible. See src/Web.ts).

## Config

See settings.json for its configuration. config.json is autogenerated for the app itself.

## CEC

It also requires CEC-CLIENT to be installed, so that CEC commands through HDMI are supported. The handler (src/CEC.ts) will spawn the daemon and handles communication, whilst providing a simple interface for the app to execute CEC commands.
